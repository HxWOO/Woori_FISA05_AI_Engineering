### 1. 딥러닝과 인공 신경망(ANN)

- **딥러닝(Deep Learning)**: 머신러닝의 한 분야로, **인공 신경망(Artificial Neural Network, ANN)** 에 기반하여 대량의 데이터로부터 복잡한 패턴을 학습하는 기술이다. 여러 층(Layer)을 거치며 데이터의 추상화 수준을 높여가는 것이 특징이다.

- **인공 신경망(ANN)**: 인간의 뇌 구조를 모방한 학습 기법으로, 노드(뉴런)와 엣지(연결)로 구성된다.
    - **인공 뉴런**: 입력값에 가중치를 곱하고, 활성화 함수를 통해 비선형성을 추가하여 출력을 생성한다.
    - **학습**: 예측과 실제 값의 오차(Error)를 최소화하는 가중치(W)와 편향(b)을 찾는 과정이며, 이때 **경사 하강법(Gradient Descent)** 이 주로 사용되었다.
    - **다층 퍼셉트론(MLP)**: 여러 개의 뉴런 층을 연결한 구조로, 각 층은 이전 층의 모든 뉴런과 연결된 **완전 연결 계층(Fully Connected Layer)** 형태를 가진다.

### 2. PyTorch와 텐서(Tensor)

- **PyTorch**: Facebook의 AI 연구소에서 개발한 오픈 소스 딥러닝 프레임워크다. **동적 계산 그래프**를 사용하여 유연한 모델 구축이 가능하며, NumPy와 유사하지만 GPU 가속을 지원하는 **텐서(Tensor)** 를 기본 데이터 구조로 사용한다.

- **텐서(Tensor)**: 다차원 배열로, 딥러닝 모델의 모든 입력, 출력, 연산의 기본 단위다.
    - **주요 속성**: `Rank`(축의 개수), `Shape`(각 축의 크기), `Type`(데이터 타입)
    - **주요 데이터 타입**:
        | 데이터 타입 | 설명 | 주요 용도 |
        |---|---|---|
        | `torch.float32` | 32비트 부동소수점 (기본) | 신경망 가중치 및 연산 |
        | `torch.int64` | 64비트 정수 (기본) | 인덱싱, 레이블 |
        | `torch.bool` | 불리언 | 논리 연산, 마스킹 |

### 3. 텐서 다루기

- **텐서 생성**: `torch.tensor()`, `torch.rand()`, `torch.zeros()`, `torch.ones()` 등 다양한 함수로 텐서를 생성할 수 있었다. 🎉

    ```python
    import torch
    import numpy as np

    # 리스트나 NumPy 배열로부터 생성
    my_list = [1, 2, 3]
    my_array = np.array([4, 5, 6])

    tensor_from_list = torch.tensor(my_list)
    tensor_from_array = torch.tensor(my_array)

    # 특정 크기의 텐서 생성
    zeros_tensor = torch.zeros((2, 3)) # 2x3 크기의 0으로 채워진 텐서
    rand_tensor = torch.rand((2, 3))   # 2x3 크기의 0과 1 사이의 균등 분포 값
    ```

- **텐서 타입 변환**: `.to()` 메서드를 사용하여 데이터 타입을 변경할 수 있다.

    ```python
    float_tensor = torch.tensor([1.0, 2.5, 3.0])
    int_tensor = float_tensor.to(torch.int64) # 결과: tensor([1, 2, 3])
    ```

- **텐서 형태(Shape) 조작**:
    - `.reshape()`: 텐서의 모양을 변경한다.
    - `.squeeze()`: 크기가 1인 차원을 제거한다.
    - `.unsqueeze()`: 지정된 위치에 크기가 1인 차원을 추가한다.

- **텐서 연산**:
    - **요소별 곱(Element-wise product)**: `*` 연산자 또는 `multiply()` 사용. 두 텐서의 같은 위치에 있는 원소끼리 곱한다.
    - **행렬 곱(Matrix multiplication)**: `@` 연산자 또는 `matmul()` 사용. 선형 대수의 행렬 곱셈을 수행한다.

- **텐서 분할 및 결합**:
    - `chunk(n)`: 텐서를 `n`개의 덩어리로 나눈다.
    - `split(size)`: 텐서를 `size` 크기의 덩어리로 나눈다.
    - `cat()`: 텐서들을 주어진 차원을 따라 연결한다.
    - `stack()`: 새로운 차원을 추가하여 텐서들을 쌓는다.

    ```python
    t = torch.rand(6)
    
    # 나누기
    chunks = t.chunk(3) # 3개의 텐서로 분할
    splits = t.split(2) # 크기가 2인 텐서들로 분할

    # 합치기
    a = torch.rand(3)
    b = torch.rand(3)
    c_cat = torch.cat([a, b])   # 크기 6의 텐서 생성
    c_stack = torch.stack([a, b]) # 2x3 크기의 텐서 생성
    ```

### 4. 자동 미분: `Autograd`

- **`Autograd`**: PyTorch의 핵심 기능으로, 텐서에 대한 모든 연산을 추적하여 **기울기(gradient)를 자동으로 계산**해준다. 이는 경사 하강법 기반의 모델 최적화에 필수적이다.

- **작동 원리**:
    1.  `requires_grad=True`로 설정된 텐서의 연산을 추적한다.
    2.  최종 결과(주로 손실 `loss`)에 대해 `.backward()`를 호출한다.
    3.  연산 그래프를 따라 역전파를 수행하며, 각 텐서의 `.grad` 속성에 기울기를 저장한다.

    ```python
    # w에 대한 l의 기울기를 계산
    w = torch.tensor(4.0, requires_grad=True)
    x = torch.tensor(3.0, requires_grad=True)

    l = (3 * w)**2 + (2 * x)**2 # l = 9w^2 + 4x^2

    # 역전파 수행
    l.backward()

    # 기울기 확인!
    print(w.grad) # dl/dw = 18w = 18 * 4.0 = 72.0
    print(x.grad) # dl/dx = 8x = 8 * 3.0 = 24.0
    ```

### 5. 실습: 경사 하강법으로 이미지 복원

- **문제**: 특정 함수(`weird_function`)에 의해 오염된 이미지를 원본으로 복원했다.

- **해결 전략**:
    1.  오염된 이미지와 동일한 크기의 **무작위 텐서**를 생성했다. (이것이 우리가 찾으려는 원본 이미지의 '후보'!)
    2.  이 무작위 텐서를 `weird_function`에 통과시켜 **가설(hypothesis) 이미지**를 만들었다.
    3.  **손실(loss)** 을 '가설 이미지'와 '실제 오염된 이미지' 사이의 거리(`torch.dist`)로 정의했다.
