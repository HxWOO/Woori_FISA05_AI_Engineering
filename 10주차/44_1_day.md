## 1. 선형 회귀 모델

선형 회귀는 연속적인 값을 예측하는 모델이다. PyTorch의 `nn.Module` 또는 `nn.Sequential`을 사용해 다층 퍼셉트론(MLP) 모델을 구성하고, 평균 제곱 오차(MSE)를 손실 함수로 사용해 학습했다.

### 핵심 개념
- **모델 구조**: `nn.Linear` 레이어를 쌓아 MLP를 구성했다.
- **활성화 함수**: `nn.ReLU`를 사용해 비선형성을 추가했다.
- **손실 함수**: `nn.MSELoss`를 사용해 예측값과 실제값의 차이를 계산했다.
- **최적화**: `torch.optim.Adam` 같은 옵티마이저로 가중치를 업데이트했다.

### 코드 구현

```python
import torch
import torch.nn as nn
from torch.optim.adam import Adam
from torch.utils.data import Dataset, DataLoader
import pandas as pd

# 데이터셋 클래스 정의
class BostonDataSet(Dataset):
    def __init__(self, X, y):
        self.X = X
        self.y = y

    def __len__(self):
        return len(self.X)

    def __getitem__(self, idx):
        return torch.FloatTensor(self.X[idx]), torch.FloatTensor([self.y[idx]])

# 데이터 준비
data_url = "https://raw.githubusercontent.com/selva86/datasets/master/BostonHousing.csv"
raw_df = pd.read_csv(data_url)
raw_df.columns = raw_df.columns.str.upper()
X = raw_df.iloc[:, :13].values
y = raw_df["MEDV"].values

dataset = BostonDataSet(X, y)
dataloader = DataLoader(dataset, batch_size=100, shuffle=True)

# 모델 정의
model = nn.Sequential(
    nn.Linear(13, 30),
    nn.ReLU(),
    nn.Linear(30, 15),
    nn.ReLU(),
    nn.Linear(15, 8),
    nn.ReLU(),
    nn.Linear(8, 1)
)

# 학습 루프
learning_rate = 0.001
optimizer = Adam(model.parameters(), lr=learning_rate)
criterion = nn.MSELoss()

for epoch in range(2000):
    for data, label in dataloader:
        prediction = model(data)
        loss = criterion(prediction, label)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    if epoch % 100 == 0:
        print(f'Epoch {epoch}: Loss {loss.item():.4f}')
```

## 2. 이진 분류 모델

두 개의 클래스 중 하나를 예측하는 모델이다. 출력 레이어에 `nn.Sigmoid` 활성화 함수를 사용해 결과를 0과 1 사이의 확률 값으로 변환하고, 이진 교차 엔트로피(BCE)를 손실 함수로 사용했다.

### 핵심 개념
- **출력 활성화 함수**: `nn.Sigmoid`를 사용해 출력을 확률로 변환했다.
- **손실 함수**: `nn.BCELoss` (Binary Cross-Entropy Loss)를 사용했다.
- **모델 평가**: 정확도(Accuracy), 혼동 행렬(Confusion Matrix), 정밀도(Precision), 재현율(Recall) 등으로 모델 성능을 평가했다.

### 코드 구현

```python
# 모델 정의 (출력층 변경)
binary_model = nn.Sequential(
    nn.Linear(13, 32),
    nn.ReLU(),
    nn.Linear(32, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
    nn.Sigmoid() # 출력을 0과 1 사이로
)

# 데이터 준비 (target을 0과 1로 변환)
median_price = raw_df['MEDV'].median()
y_binary = (raw_df['MEDV'] >= median_price).astype(int).values

dataset_binary = BostonDataSet(X, y_binary)
dataloader_binary = DataLoader(dataset_binary, batch_size=64, shuffle=True)

# 학습 루프
optimizer_binary = Adam(binary_model.parameters(), lr=0.001)
criterion_binary = nn.BCELoss() # 이진 분류 손실 함수

for epoch in range(500):
    for data, label in dataloader_binary:
        prediction = binary_model(data)
        loss = criterion_binary(prediction, label)
        optimizer_binary.zero_grad()
        loss.backward()
        optimizer_binary.step()
    if epoch % 50 == 0:
        print(f'Epoch {epoch}: Loss {loss.item():.4f}')

# 모델 평가
binary_model.eval()
with torch.no_grad():
    # ... (평가 코드)
    pass
```

## 3. 다중 분류 모델 (Softmax)

세 개 이상의 클래스를 분류하는 모델이다. 출력 레이어에서 각 클래스에 대한 점수(logit)를 계산하고, 이를 `Softmax` 함수를 통해 확률 분포로 변환했다.

### 핵심 개념
- **Softmax 함수**: 모델의 출력을 모든 클래스에 대한 확률 분포로 변환한다. 모든 확률의 합은 1이 된다.
- **손실 함수**: `nn.CrossEntropyLoss`를 사용한다. 이 손실 함수는 내부적으로 `Softmax`와 `NLLLoss`(Negative Log Likelihood Loss)를 결합해 계산하므로, 모델의 마지막 레이어에 `Softmax`를 추가할 필요가 없다.

### 코드 구현 (개념)

```python
import numpy as np

def softmax(x):
    """Numpy로 Softmax 함수 구현"""
    exp_x = np.exp(x - np.max(x)) # 오버플로우 방지를 위해 최댓값을 빼줌
    return exp_x / np.sum(exp_x)

# 예시
scores = np.array([1.3, 5.1, 2.2, 0.6, 1.1])
probabilities = softmax(scores)
print("Softmax Probabilities:", probabilities)
print("Sum of Probabilities:", np.sum(probabilities))
```

## 4. MNIST 손글씨 분류

다중 분류의 대표적인 예제로, 0부터 9까지의 손글씨 이미지를 분류했다. 입력 데이터는 28x28 픽셀의 이미지이며, 이를 1차원 벡터(784)로 펼쳐 모델에 입력했다.

### 핵심 개념
- **데이터셋**: `torchvision.datasets.MNIST`를 사용해 데이터를 쉽게 불러왔다.
- **데이터 전처리**: `transforms.ToTensor()`를 사용해 이미지를 텐서로 변환하고 픽셀 값을 [0, 1] 범위로 정규화했다.
- **모델 구조**: 입력층은 784개의 노드를, 출력층은 10개(0~9)의 노드를 가진다.
- **평가**: `argmax`를 사용해 가장 높은 확률을 가진 클래스를 예측값으로 선택하고 정확도를 계산했다.

### 코드 구현

```python
from torchvision.datasets.mnist import MNIST
from torchvision.transforms import ToTensor

# 데이터 로드
training_data = MNIST(root="./", train=True, download=True, transform=ToTensor())
test_data = MNIST(root="./", train=False, download=True, transform=ToTensor())

train_loader = DataLoader(training_data, batch_size=64, shuffle=True)
test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

# 모델 정의
class MNIST_Classifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(28 * 28, 128)
        self.fc2 = nn.Linear(128, 64)
        self.output = nn.Linear(64, 10)

    def forward(self, x):
        x = x.view(x.size(0), -1) # 2D 이미지를 1D 벡터로 펼침
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.output(x) # CrossEntropyLoss가 Softmax를 포함하므로 그대로 출력
        return x

mnist_model = MNIST_Classifier()
criterion_mnist = nn.CrossEntropyLoss()
optimizer_mnist = Adam(mnist_model.parameters(), lr=0.001)

# 학습 루프
for epoch in range(5): # 예시로 5 에포크만 실행
    for data, labels in train_loader:
        outputs = mnist_model(data)
        loss = criterion_mnist(outputs, labels)
        optimizer_mnist.zero_grad()
        loss.backward()
        optimizer_mnist.step()
    print(f"Epoch {epoch+1}, Loss: {loss.item():.4f}")

# 평가
mnist_model.eval()
correct = 0
total = 0
with torch.no_grad():
    for data, labels in test_loader:
        outputs = mnist_model(data)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

print(f'Test Accuracy: {100 * correct / total:.2f}%')
```
MNIST 분류 정확도 95% 이상 달성! 🚀
